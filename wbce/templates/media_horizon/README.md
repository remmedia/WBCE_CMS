# MEDIA Horizon

Installierbares Frontend-Template für WBCE CMS 1.6.8, 1.7 und 2.7.

## WBCE-Zuordnung

- Menü 1: Hauptnavigation, bis zu fünf Ebenen
- Menü 2: schmale Servicenavigation oberhalb des Headers
- Menü 99: wird nicht ausgegeben
- Block 1: Hauptinhalt
- Block 2: optionale Hero-Karte, etwa für Suche, MiniForm oder Handlungsaufforderungen
- Block 3: Teaser und Karten unterhalb des Hauptinhalts
- Block 4: Footer-Inhalte und Footer-Links
- Block 99: wird nicht ausgegeben

Ein optionales Hero-Bild kann als `/media/media-horizon-hero.jpg` hochgeladen werden. Ohne Bild verwendet das Template einen hellen, kontrastreichen Farbverlauf.

Das Haken-Signet wird als SVG-Favicon sowie als Browser-, Apple-, Android-, Safari- und Windows-Symbol mitgeliefert.

## Barrierefreiheit

Das Template nutzt semantische Landmarken, einen Sprunglink, Tastaturbedienung, sichtbare Fokusmarkierungen, `aria-current`, ausreichend große Bedienflächen, responsive Typografie, `prefers-reduced-motion` und Unterstützung für erzwungene Kontrastfarben. Die redaktionellen Inhalte müssen weiterhin mit sinnvollen Überschriften, Alternativtexten, Linktexten und Formularbeschriftungen gepflegt werden.
